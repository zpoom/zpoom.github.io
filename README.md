# Vibe profile page

## Release: Terminal UI

- **Tab Title**: The browser tab title has been updated to "Poom's Profile" for better identification.
- **Favicon**: Added a terminal icon (`terminal-icon.svg`) as the favicon to enhance the visual appearance of the browser tab.
- **Terminal UI**: Applied a fixed size for the terminal on desktop screens and added rounded corners with an 8px border radius.
- **Command Styling**: Updated input command text color to white and styled unknown commands with red text for better visibility.
- **Suggestions**: Implemented a feature to display command suggestions in grey text, with auto-completion using the Tab or Right Arrow
